# v0.4.6

## 会话是第一类对象

- 会话落库为四张表（会话 / 席位 / 关联工件 / 消息），消息带线程关系与回执关系。
- 聊天页改为会话驱动：左栏是会话列表（可按 agent、按关联工件分组），右侧是会话主体。
  没有会话的旧对话仍保留在列表下方，老用法不受影响。
- 会话可热加入成员，席位带在场状态（闲 / 在听 / 在干 / 卡住 / 已退出）。
- 群聊：@ 定向必醒、非 @ 按需自取；唤醒集合由确定性函数算出（不靠模型自评）；
  群内消息互相可见并可接力。

## 结论要过复核这一关

- 漏洞结论不再「落库即已验证」：新增未验证 / 已验证 / 不成立三态。
- 复核不通过可以**退回返工**：结论打回给产出它的那条意图，理由与去向都留痕。
- 提出人不能自己复核自己的结论；已结案的结论不能被翻案；打回或不成立必须写理由。
- 复现证据引用在记录时写入，不再是永远为空的占位列。

## 记忆、进度与长会话

- 记忆层：只追加、带版本、可取代、按作用域隔离，索引只指向规则、不存放规则；
  导出为纯文本。记忆是提示辅助，不是安全机制。
- 索引有上限，写入超限时**直接拒绝**，绝不静默截断。
- 任务进度回执：进度落在库里，压缩对话不会把进度抹掉。
- 对话压缩后提醒模型把进度写进文件（压缩拿不走的东西）。
- 压缩触发点可提前（只能提前、不能推后），前台命令上限 60 秒。
- 后台命令可跨运行存活，有归属、有回收者、有完成提醒，回收时标为「已回收」而非「失败」。

## 出网治理与安全

- 出网范围校验真正接线（三类角色带任务身份，网页抓取也带身份）。
- 搜索出口走**范围豁免清单**：清单是代码常量，不是可热改的配置。
- 应用改用受限数据库角色：直连改库这条路在数据库权限层被挡住；
  迁移与运行用两条连接，凭据可轮换。

## 其它

- 任务大厅并入会话体系：额度与并发从数字改成状态语义（含「读不出来」也算需要人看一眼）。
- 大厅可检索、可看关联面板（任务 / 策略 / 资产）、空态有明确文案。
- 记忆检索按完整度分级（完整 / 部分 / 不足），混合检索用 RRF 融合。
- 会话时间线支持线程折叠与收件条摘要。
- CI 门禁修复：前端 lint 真正参与门禁，测试真正在跑。
