> 依据开发纪律 §3：后端每个功能点必须有前端可见入口（页面 / sidebar / tab / agent 选择器其一），
> 或在本表明确标注「行为面，无独立 UI」。
>
> 本表是 **0.13.3 全量审查后的基线快照**。此后每次对齐检查的结果写进对应版本的
> CHANGELOG，本表随批次更新；「待接入」条目必须有排期批次。

## 二、行为面，无独立 UI（有意为之，写明理由）

| 后端面 | 理由 |
|---|---|
| GET /api/traffic/blob | 原始包体字节面，流量页经 /api/traffic/exchange 取解析面；blob 供导出/取证脚本 |
| POST /api/gc | 运维动作（回收内存/临时态），无状态可展示；从系统配置页触发无增益 |
| POST /api/companies/reattribute | 批量重归属是低频危险动作，现经公司范围编辑间接完成；独立入口待批次排期 |
| GET /api/conversations/runs | 会话运行快照面，对话页的会话流已覆盖其展示职责 |
| POST /api/legacy/distill/{taskID} | 蒸馏由任务收尾链路自动触发，人工入口与传承图页的既有交互重叠 |
| GET /api/exploration/activity/*（stream/history/{seq}） | SSE/历史面，仪表盘与发现页的活动流已消费 |
| GET /api/logs/stream、GET /api/update/stream | SSE 推送面，日志页与系统配置页（更新卡）已消费 |
| /api/sessions/{id}/context、context-grants、digest、timeline | 会话上下文/摘要/时间线面——**随 ROADMAP 会话群聊化批次接入**（后端已落，前端排期项；此前出现在真缺口清单，0.13.3 明确标注为待接入而非行为面） |
| /api/strategies/curation、edges、utility | 策展队列/关联边/效用面——策略库页已展示 assembled/proposals/pin-queue 三面；三者的 UI 随策略库迭代批次接入 |
| GET /api/skills/missing、POST /api/skills/upload | Skill 页的安装向导批次排期项 |
| GET /api/intercept/judge/usage | 裁判模型用量面，拦截页的裁判配置区已展示核心状态；明细随拦截页迭代接入 |
| GET /api/visibility/{kind}/{id} | 可见性详情面（列表面已入各配置页），详情 API 供既有 toggle 复核 |
| GET /api/task-archives、POST batch | 归档列表面已入任务页归档视图；batch 供列表勾选批量操作复用 |
