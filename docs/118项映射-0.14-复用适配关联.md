## 2. 映射纪律

1. **复用优先**：映射表中没有任何一项以「新建平行实体」为调整方向——新建的只有缺失层（TI 领域对象四表、事件 outbox、调度规则），既有资产（edge/biz/findings/traffic/资产图/报告/记忆/评测）全部原位复用。
2. **适配不重写**：exploration.edge / modeling.business 两个能力以现有工具族为适配层（0.15.68 TI-10 边界决策），不建新 adapter 包。
3. **关联靠引用列**：跨对象关系一律走 0.15.63 的引用列与 correlation/causation 身份列，不复制主体数据。
4. **调整方向显式登记**：每个「调整项」都指向具体的接线任务或后续卡，不落在「以后再说」。

## 3. 本批不做

不改 D-13 算力档、不动 E-* 晋级逻辑、不扩展报告生成器（各归其卡）。
